HTML Basics

  • Use semantic tags like <header>, <main>, and <section>.
  • Always include a title and meta viewport in the document head.
  • Forms are created with <form>, <input>, and <button>.
  • Links use <a href="...">, and images use <img src="...">.
<h1>Hello Techspire!</h1> <p>Welcome to web development.</p> <a href="https://example.com">Visit</a>

CSS Cheatsheet

  • Use CSS selectors like p, .card, #header, and button:hover to style elements precisely.
  • Use the box model: padding controls inside space, margin controls outside space, and border creates the visible outline.
  • Set colors with color, background, and border. Use hex, rgb, rgba, or named colors.
  • Use display: flex to align items in rows/columns and display: grid for more advanced layouts.
  • Control layout with justify-content and align-items for flexbox, or grid-template-columns for grid.
  • Make responsive pages with max-width, width: 100%, and media queries like @media (max-width: 768px).
  • Use position: relative, absolute, and fixed carefully for overlays, sticky headers, and navigation.
  • Apply hover states with :hover and focus states with :focus to improve interactivity.
  • Use box-shadow and border-radius to create cards, buttons, and modern UI effects.
  • Typography basics: font-family, font-size, font-weight, line-height, and letter-spacing improve readability.
.card { width: 100%; max-width: 420px; padding: 20px; margin: 16px auto; background: #121b2b; border: 1px solid rgba(255,255,255,0.08); border-radius: 12px; box-shadow: 0 10px 25px rgba(0,0,0,0.2); } .card:hover { transform: translateY(-2px); } @media (max-width: 768px) { .card { padding: 14px; } }

JavaScript Basics

  • Use let and const for variables.
  • Functions let you reuse blocks of logic.
  • if, else, and loops control program flow.
  • DOM APIs like document.querySelector() update the page dynamically.
const button = document.querySelector("button"); button.addEventListener("click", () => { alert("Hello from JavaScript!"); });

Quick Beginner Checklist

  • Learn HTML structure.
  • Style pages with CSS.
  • Add interaction with JavaScript.
  • Build small projects like a landing page or calculator.
  • Practice every day and keep your code clean.
