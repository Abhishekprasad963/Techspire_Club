HTML Full Guide

  • HTML gives a webpage its structure. Start with <!DOCTYPE html>, then use <html>, <head>, and <body>.
  • Add <title> for the browser tab and <meta name="viewport"> so the page works well on phones.
  • Organize content with semantic tags such as <header>, <nav>, <main>, <section>, <article>, and <footer>.
  • Use headings from <h1> to <h6> in a logical order. A page should normally have one main <h1>.
  • Write paragraphs with <p>, important text with <strong>, and lists with <ul>, <ol>, and <li>.
  • Links use <a href="...">. Use relative links for your own pages and full URLs for external websites.
  • Images use <img>. Always include useful alt text so screen readers can describe them.
  • Add video and audio with <video> and <audio>. The controls attribute gives visitors playback controls.
  • Tables use <table>, <tr>, <th>, and <td>. Use them for data, not page layout.
  • Forms are created with <form>, <label>, <input>, <textarea>, and <button>. Connect labels to inputs with matching for and id values.
  • Common input types include text, email, password, number, date, and checkbox. Use required for fields that must be completed.
  • HTML attributes add information or behavior. Useful examples include class, id, href, src, target, aria-label, and data-* attributes.
  • Prefer semantic HTML and keyboard-friendly controls. Use a real <button> for actions instead of making a clickable <div>.
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>My First Page</title> </head> <body> <header> <h1>Hello Techspire!</h1> <nav> <a href="index.html">Home</a> </nav> </header> <main> <section> <h2>Welcome</h2> <p>Build, learn, and create.</p> <img src="team.jpg" alt="Techspire team" /> </section> </main> <footer>Made by Techspire Club</footer> </body> </html>
<form> <label for="email">Email</label> <input id="email" name="email" type="email" required /> <label for="message">Message</label> <textarea id="message" name="message"></textarea> <button type="submit">Send</button> </form>

CSS Cheatsheet

  • Use CSS selectors like p, .card, #header, and button:hover to style elements precisely.
  • Use the box model: padding controls inside space, margin controls outside space, and border creates the visible outline.
  • Set colors with color, background, and border. Use hex, rgb, rgba, or named colors.
  • Use display: flex to align items in rows/columns and display: grid for more advanced layouts.
  • Control layout with justify-content and align-items for flexbox, or grid-template-columns for grid.
  • Make responsive pages with max-width, width: 100%, and media queries like @media (max-width: 768px).
  • Use position: relative, absolute, and fixed carefully for overlays, sticky headers, and navigation.
  • Apply hover states with :hover and focus states with :focus to improve interactivity.
  • Use box-shadow and border-radius to create cards, buttons, and modern UI effects.
  • Typography basics: font-family, font-size, font-weight, line-height, and letter-spacing improve readability.
.card { width: 100%; max-width: 420px; padding: 20px; margin: 16px auto; background: #121b2b; border: 1px solid rgba(255,255,255,0.08); border-radius: 12px; box-shadow: 0 10px 25px rgba(0,0,0,0.2); } .card:hover { transform: translateY(-2px); } @media (max-width: 768px) { .card { padding: 14px; } }

JavaScript Basics

  • Use let and const for variables.
  • Functions let you reuse blocks of logic.
  • if, else, and loops control program flow.
  • DOM APIs like document.querySelector() update the page dynamically.
const button = document.querySelector("button"); button.addEventListener("click", () => { alert("Hello from JavaScript!"); });

Quick Beginner Checklist

  • Learn HTML structure.
  • Style pages with CSS.
  • Add interaction with JavaScript.
  • Build small projects like a landing page or calculator.
  • Practice every day and keep your code clean.
